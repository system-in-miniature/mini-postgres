# MiniPostgres Behavior Evidence

The complete evidence table is maintained at the repository root:
[read `BEHAVIOR_MATRIX.md`](https://github.com/system-in-miniature/MiniPostgres/blob/main/BEHAVIOR_MATRIX.md).

The matrix links implemented behavior to focused pytest nodes. Use it after the
[behavioral contract](behavioral-contract.md): the contract states what must be
observable, and the matrix identifies the test that proves it.

For a guided subset grouped by mechanism, continue with the
[hands-on labs](labs-guide.md).
